# 0.4.0 のツール

今までの会話画面から、ファイルの確認、フォルダー内の検索、コマンド実行を依頼できます。ミントは必要なツールを選び、これまでの声・Live2D・人格を保って日本語で答えます。実行履歴は折りたたみ欄に表示され、入力、出力、エラーを確認できます。「中止」はモデルへの要求を停止し、実行中のコマンドが終了するまで待ちます。すでに行った変更は残ります。

設定の「ツールとスキル」で有効化と作業フォルダーを指定します。空欄ならアプリのデータフォルダー内の `agent-workspace` を使います。絶対パスを指定すれば、現在の Windows ユーザーが利用できる他の場所にもアクセスできます。呼び出しごとの確認はありません。コマンドは Windows PowerShell で実行します。既存の会話に追加する小さな機能で、別のエージェント画面やモデル設定はありません。

## 使い方

- 「このフォルダーの一覧を確認して、指定したログを読んでください。」
- 「設定ファイルとログを確認して、実際のエラーを教えてください。」
- 「`[Console]::WriteLine('HELLO_MINTO')` を実行して、実際の終了コードを教えてください。」

UTF-8 テキストを読み、既定では200行を取得します。文字列検索は完全な文字列で行い、最大200件・2,000ファイルまでです。検索対象は512 KiB以下、直接の読み取りは2 MiB以下です。大きなファイルには適切なコマンドやスキルを使います。ツールの出力は24,000文字までで、省略を明記します。

## 高度な設定（任意）

折りたたみ欄で実行ステップ数（1～50、既定12）とコマンドの時間制限（5～600秒、既定60）を設定できます。一つのステップは一回のモデル要求で、ツールは順番に実行します。上限に達したら、確認済みの結果と未完了の作業を伝えます。

MCP は JSON 配列です。stdio は `id`、`transport: "stdio"`、`command`、`args`、任意の `env` を使います。Streamable HTTP は `id`、`transport: "http"`、`url`、任意の `headers` を使います。実際のコマンド・引数・URLは接続するサーバーの文書で確認してください。サーバーのインストールは行いません。IDは重複できません。`env` と `headers` は Windows safeStorage で暗号化し、画面では値を隠します。保存済みの値を使う場合は `__MINTO_KEEP_SECRET__` を保持し、変更する場合は新しい値を入力します。チェックは接続と一覧取得のみです。OAuth ログインと旧式の HTTP SSE はこの版に含めません。

スキルの設定はルートフォルダーの JSON 配列です。その下に各スキルのフォルダーを置き、YAML frontmatter 付き `SKILL.md` の `name` と `description` を指定します。名前はフォルダー名と一致し、重複できません。インポートは選んだスキルをデータフォルダーの `skills` にコピーします。ミントは説明の一覧から選び、必要な本文と参照資料だけを読み込みます。`file-inspection` と `command-workflow` を同梱します。スクリプトはコマンドツールで実行し、文書に書かれた実行環境が必要です。リンクのインポートを拒否し、依存環境を自動インストールしません。

従来の会話、好感度、セーブは引き続き使えます。ツールの結果を新しいユーザー発言の好感度根拠にしません。画面・ファイル・ツールの内容は資料として扱い、人格や依頼を書き換える権限を与えません。
