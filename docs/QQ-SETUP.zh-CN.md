# 0.6.0 QQ 连接与记忆

桌面助手负责人格、模型、TTS 和记忆；外部 AstrBot 插件连接 NapCat / OneBot v11。NapCat、AstrBot 和 QQ 客户端分别安装，不包含在桌宠发行包中。登录验证由账号本人完成。

## 配置

1. 打开设置中的 QQ，明确填写机器人 QQ 号，选择绑定存档并保存。唯一主人固定为 `2992576898`，机器人应使用另一个账号。
2. 私聊默认只回应主人；群聊从列表中逐个开启。共享备注只填写允许在 QQ 公开的资料。完整桌面对话只在主人私聊中提供，其他人不能凭昵称取得身份。
3. 安装外部 AstrBot 插件包 `astrbot_plugin_minto_bridge-0.6.0.zip`。完整插件部署说明见 [桥接指南](../integrations/astrbot_plugin_minto_bridge/README.md)。AstrBot 与 NapCat 使用同一个实际登录账号。
4. 在 QQ 页点击显示桥接配对信息，将地址和令牌按桥接指南配置到本机插件。令牌不要发送到群聊。桌面令牌使用 Windows 安全存储加密；首次自动分配的端口会记住，重新启动保持同一地址。端口被占用时会显示错误，不会偷偷更换地址。
5. 先启用一个测试群，由本人 @ 薄荷验证文本、图片与可选日语语音，再逐群开启。关闭 AstrBot 对这些消息的其他自动回复，避免多个插件同时发言。

## 日常操作

- 群/好友列表可以刷新；选择会话可查看收发状态、错误、触发原因和引用，手动发文字或请求撤回已确认发送的消息。撤回最终由 QQ 平台决定。
- 支持 @、关键词、短暂跟进和表情抽样，均可按会话调整。动态图片当前不解析；图片下载失败时不会捏造看图内容。
- QQ 正文以短中文为主。日语语音单独投递，失败时保留文字而不重复发送。桌面忙碌或禁用语音时显示原因并只发送文字。
- 取消回复只能取消尚未发送的内容；已经发出的消息需要另行撤回。

在桌面开启工具调用后，可说“在群聊 123456 里自我介绍”或指定真实群名。薄荷通过真实群列表核对目标，并在 QQ 发送简短中文；默认不介绍主人的私人关系。只有当前桌面用户的明确指令能授权此操作，自动观察和群聊资料不能代为授权。工具显示排队并不代表 QQ 已送达，最终状态在 QQ 管理页查看。

其他人的态度按好感 30—59 的朋友或陌生人处理；只有主人沿用绑定存档的实际好感。

## 记忆边界

`机器人账号 + 绑定存档 + 会话类型 + 群/好友号` 联合隔离。各群保持独立摘要、固定备注、来源索引和历史；不能读取另一个群的上下文。主人在桌面可以读取带群来源的概要索引；其他好友的私聊不会汇入群索引。

有变化的会话每 20 分钟尝试归档。使用近期消息、当前会话原文检索、原文引用摘要和固定备注控制上下文长度；不会宣称压缩保留了所有细节。空归档推进游标，不反复处理寒暄。精确历史以会话记录为准。

固定备注优先于自动摘要，可以修正。遗忘此前历史会建立持久的时间边界，旧历史补取、撤回内容和迟到摘要不能重新进入记忆。历史仍保留在本机审计时间线，遗忘不等于删除聊天文件。

QQ 数据与加密配对信息保存在实际数据目录的 `qq` 子目录；备份完整数据目录时一并保留。普通存档 JSON 导出仍只导出桌面存档，QQ 数据不会自动装入其中。

## 验证范围

本地模拟测试覆盖 HTTP、真实 Electron 窗口、流式中文、图片、隔离、遗忘、防重及语音通路。真实 QQ 登录、群内收发与平台兼容性需要实际账号完成验收；不能用模拟测试代替。
