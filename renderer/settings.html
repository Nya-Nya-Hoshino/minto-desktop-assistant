界面与启动

请输入本机已安装的字体名称；缺失时使用系统备用字体。字号只调整界面文字。

免安装版启用自启后，请保持程序目录位置不变。

主模型

填写服务实际提供的完整兼容地址和精确模型 ID。地址需止于 API 基础路径，程序追加 /chat/completions。公开对话和语音使用日语。

勾选后，截图、提问和对话历史直接交给主模型。请根据模型实际能力选择。

备用视觉模型（可选）

主模型不支持图片，或图片请求被拒绝时使用。鉴权、限流和网络错误不会触发切换。

屏幕观察

锁屏、忙碌、配置不完整、画面未变化或没有适合的话题时暂停发话。托盘菜单也可暂停。

日语语音与口型

连接本地 Style-Bert-VITS2 服务。只有实际加载的模型会进入已连接状态；音频振幅驱动口型。

工具与技能

工具使用当前 Windows 用户的完整权限执行命令、读写文件和调用已配置的 MCP 服务，不逐项请求确认。可随时在对话窗口停止。

留空时使用应用数据目录下的 agent-workspace，并自动创建。请填写实际存在的目录。

高级工具设置

填写 JSON 数组。stdio 项使用 id、transport、command、args、env；http 项使用 id、transport、url、headers。已保存的 env 与 headers 值显示保留标记；保留该标记可继续使用原值，填写新值可替换。

填写技能根目录路径字符串的 JSON 数组；根目录下各技能文件夹包含 SKILL.md。导入会复制技能目录到应用数据目录。

检查只连接 MCP 并读取工具清单和技能，不执行工具。

恋人关系与好感

延续游戏中的恋人关系。初始好感 60，亲密请求阈值 80。关心、尊重与修复关系可小幅加分；施压和羞辱会扣分。每日增长上限可设置，最高 20 分。重复发言和自动搭话不加分。高好感仍需双方意愿。

独立存档

每个存档分别保存完整对话、长期摘要和服装。切换存档会取消正在进行的请求与语音。导出不包含服务配置或 API 密钥。

数据目录
