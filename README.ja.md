# MintoAssistant

## 0.4.0 ツール機能

今までの会話画面でファイル確認、検索、PowerShell 実行を依頼できます。MCP とスキルの設定は従来の設定画面の折りたたみ欄にあります。現在のユーザー権限で自律的に実行し、個別の確認は行いません。実行履歴を開いて結果を確認し、中止できます。[ツールの使い方](docs/TOOLS.ja.md)を参照してください。


日本語・JSON の再生成時も元のユーザー発言と画像を保持し、その発言に対して好感度を評価します。内部の修正指示を新しい発言として扱いません。

自動観察と通常の会話では日本語の返答を保持し、表情などの項目を別に整理します。空の応答は一度だけ再試行し、不完全な応答には明確なエラーを表示します。

ミントの返答を右クリックし「Markdown で読む」を選ぶと、移動・サイズ変更できる小窓で見出し、リスト、表、コードを確認できます。「プレビュー／原文」を切り替えられ、原文は保存済みの返答と一致します。過去の会話も閲覧できます。

## 0.3.0 恋人関係と付き添い

各セーブはゲームの恋人関係を引き継ぎ、好感度 **60/100**、親密なお願いのしきい値 **80** から始まります。気遣い、尊重、誠実な謝罪は最大 +1、侮辱は -2、強制は -3 です。1日の上昇上限は既定で3、設定で1から20の整数に変更できます。同じ入力の24時間以内の繰り返しと自動会話では加点しません。モデルは現在のユーザー発言の評価と完全一致する根拠を返し、数値の更新はアプリが行います。高い好感度でも合意を強制せず、低下しても過去の恋人関係を否定しません。好感度は再起動、切り替え、インポート・エクスポートで維持され、旧セーブも会話履歴を保持したまま同じ初期関係を得ます。

アプリは `assets/skills/minto-persona.md` の人格スキルを読み込みます。二部の物語を改めて要約し、出典の行番号を記載しています。元のシナリオと引用の照合資料はローカルの `private/persona-corpus-030` に保存します。初期の家事や魔法の不得意と、その後の成長を区別します。物語の記憶を、現在のデスクトップ上で実際に起きた身体的な出来事として捏造しません。

画面を見る会話は、最近の話題とミントの気遣いを重視します。画面を機械的に列挙せず、具体的な文字やエラーを質問された時にその説明をします。自動会話は既定で2分間隔で試み、変化のない画面も再確認します。処理中、音声再生中、ロック中、範囲選択中、一時停止中は待機し、ユーザーとの会話後に間隔を再開します。設定に状態、前回の観察、前回の声かけ、実際のエラーを表示します。保存済みの画面IDが消え、実画面が一つだけの場合にそのIDへ更新し、選択範囲は維持します。複数の画面がある場合は再選択が必要です。

## ローカル配布物を起動する

インストーラー版は `MintoAssistant-Setup-0.4.0-windows-x64.exe` を実行し、保存先を選びます。現在の Windows ユーザー向けにインストールします。

ポータブル版は ZIP 全体を書き込み可能なフォルダーに展開し、`MintoAssistant.exe` を実行します。`portable.flag`、`resources`、すべての DLL を同じ構成のまま保持してください。ユーザーデータは EXE の隣の `data` フォルダーに保存されます。

キャラクターをクリックすると半透明の会話吹き出しと入力欄が開きます。ドラッグで移動し、マウスホイールでサイズを調整できます。視線はキャラクターウィンドウ外を含むデスクトップ上のマウスポインターを追います。元のモデルにある表情・ポーズ・手・耳の動作を利用し、音声再生に合わせて口が動きます。

キャラクターまたはトレイアイコンを右クリックするとメニューが開き、トレイアイコンをダブルクリックすると設定が開きます。設定で中国語・英語・日本語の表示言語を選べます。表示言語を変更しても、キャラクターの返答と音声は日本語のままです。中国語で入力することもできます。

表示設定でローカルのフォントと 10〜28 の文字サイズを選べます。キャラクターの大きさは変わりません。Windows ログイン時の自動起動は既定で無効で、配布版で有効にできます。ポータブル版で有効にした後は保存先を移動しないでください。

## 会話と画像理解の設定

メインモデルの提供元、API ベース URL、正確なモデル ID、API キーを設定します。予備の画像モデルは任意です。アプリはベース URL に `/chat/completions` を追加します。提供元が実際に用意している OpenAI 互換エンドポイントを指定してください。画像理解に使うモデルには画像入力の対応も必要です。選択肢には DeepSeek、OpenAI、Gemini、Grok、カスタム互換サービスがあります。

保存後に接続テストを実行します。このローカル環境で確認した DeepSeek 設定は、ベース URL `https://api.deepseek.com`、モデル ID `deepseek-flash`、推論強度 `high` です。提供元でのモデル提供が永続することを保証する記載ではありません。API キーは Windows の保存機能で暗号化し、ソースや配布物に開発用の認証情報は含めません。

公開する返答は日本語です。アプリは返答の構造と表情・ポーズの対応を確認してから表示します。不正な出力やサービスエラーは画面に表示されます。

## 画面観察

メインモデルを一つ設定し、画像対応なら「メインモデルは画像などのマルチモーダル入力に対応」を選択してください。画像・質問・最近の履歴をまとめて送ります。予備の画像モデルは任意の折り畳み設定です。画像対応を未選択、またはメインモデルの画像要求が HTTP 400/415/422 で拒否された場合に予備モデルで分析し、メインモデルが返答します。認証・レート制限・通信エラーでは切り替えません。物理解像度で取得してから切り抜き、過去の説明より今回の画像を優先します。画像はセーブに保存しません。

設定で観察するディスプレイを選択します。会話に画面を添付でき、単独の画面操作でも最近の会話を踏まえた自然な声かけを行います。自動観察は既定で120秒間隔で試み、変化がない画面も再確認します。他の処理中、音声再生中、ロック中、範囲選択中は待機します。設定またはトレイメニューから一時停止できます。

スクリーンショットは現在のリクエストのために設定した画像理解サービスへ送信します。セーブには観察の要約と時刻を保存し、画像ファイルは保存しません。

設定で「画面全体」または「選択範囲」を選びます。対象のディスプレイを選び、「範囲を選択」で矩形をドラッグし、離すと保存します。Esc または右クリックで取り消すと、保存済みの画面と領域は変わりません。会話画面の範囲選択ボタンは選択後に観察します。手動観察、会話への画像添付、画像サービスの接続テスト、定期観察は同じ保存済み範囲を使います。選択中は定期観察を止めます。

## 音声モデル

完成済みのローカル配布物では、同梱 CPU 音声サービスをアプリが自動で起動・終了します。既存の外部 Style-Bert-VITS2 サービスを使う場合は、その HTTP ベース URL を指定します。

英語の名前は会話表示とセーブにそのまま残します。英字を含む返答だけ、設定した会話サービスへの追加リクエストで読み上げ用のカタカナ原稿に変換します。日本語だけの返答は直接ローカル音声合成へ送ります。発音原稿が無効な場合はエラーを表示します。

独自モデルは、`.safetensors` 1 個、`config.json`、`style_vectors.npy` を含むフォルダーから取り込みます。ファイルはユーザーデータへコピーされ、元のフォルダーは保持されます。話者とスタイルはモデルの実際のメタデータから選びます。現在のミント重みが提供する話者は `ミント`、スタイルは `Neutral` です。

[ローカル学習の継続と新しい重みの反映](docs/TRAINING.ja.md)では、総 epoch 数、再開用の学習状態、留出音声での比較、選択したモデルの取り込み、同梱の既定モデルの更新を説明しています。

## 会話セーブ

設定から独立したセーブの作成、名前変更、切り替え、書き出し、読み込み、削除ができます。セーブごとに完全な会話、長期要約、衣装を保存します。モデルへ渡す履歴の長さを制限しても、保存済みの会話は削除しません。セーブ切り替え時は実行中のリクエストと音声を止めます。書き出しには提供元の設定と API キーを含めません。

インストール版は現在のユーザーのアプリケーションデータを使用します。設定に正確な保存先とフォルダーを開く操作があります。データ全体をバックアップする際はアプリを終了してからコピーしてください。暗号化したキーは Windows ユーザー環境に紐づくため、別のコンピューターでは再設定します。

## Windows での開発とビルド

Node.js/npm 環境を用意します。Electron の固定バージョンは 44.3.0 です。開発時のユーザーデータは `_data` に保存します。以下のローカルファイルを、後述するインストール・テスト・起動・ビルドのコマンドを実行する**前**に用意してください。テストは実際のモデルファイルを確認するため、素材がない状態では失敗します。

起動・ビルドの前に、`assets/skins.json` が指定するキャラクターファイルを `assets/minto` に配置し、キャラクター設定も用意してください。別のモデルを使う場合は、そのモデルから確認した識別子に合わせて動作・パラメーターの対応を調整します。除外したキャラクター素材はソース取得だけでは表示できません。

プロプライエタリな Cubism Core JavaScript は、既存の利用権のあるローカルコピーから正確な保存先 `libs/live2dcubismcore.min.js` に配置します。GitHub には含めません。モデルやレジストリーのメタデータは、この実行ライブラリーの代わりにはなりません。

`runtime` には、使用権のある完全なローカル音声環境を配置します。既存の個人用配布物を再利用する場合は、アプリを終了してから `resources/runtime` 全体をコピーできます。このフォルダーには組み込み Python、依存パッケージ、OpenJTalk 辞書、日本語 BERT、音声アダプター、音声モデル、ライセンスを含みます。相対パスの構成を保ってください。その配布物から再ビルドする場合は、`resources/runtime/licenses/Style-Bert-VITS2-source.zip` を `build/Style-Bert-VITS2-source.zip` にもコピーします。ローカル学習環境の依存ロックは pip のバージョンを記録するもので、組み込み Python、DLL、辞書、重みの代わりにはなりません。

必要なローカルファイルを配置した後、取得したソースのフォルダーで実行します。

```powershell
npm ci
npm test
npm start
```

ビルドの前に、起動中の開発版アプリを終了します。

```powershell
npm run build
npm run package:audit
```

インストーラーとポータブル ZIP は `dist` に出力し、ハッシュは `dist/SHA256SUMS.txt` に記録します。`npm run build:portable` は ZIP だけを作成します。提供元の認証情報、ユーザーのセーブ、学習音声、最適化状態、テストデータ、キャッシュは梱包しません。表示言語の切り替えと英語・日本語文書は配布設定に含めます。

## アプリのソースやローカル配布物を更新する

更新前にアプリを終了し、データフォルダー全体をバックアップします。正確な保存先は設定に表示され、ポータブル版では EXE の隣の `data` フォルダーです。GitHub から除外するローカルファイルの `assets/minto`、`libs/live2dcubismcore.min.js`、完全な `runtime` もバックアップします。学習環境は別途保持してください。

GitHub のソースを取得したフォルダーで `git pull` を実行します。これらのローカルファイルと必要な `build/Style-Bert-VITS2-source.zip` を復元または確認してから、`npm ci`、`npm test`、`npm run build` を実行します。ソース更新では、除外したキャラクター素材や学習済み音声重みはダウンロードされません。

インストール版は同じ Windows ユーザーで新しいインストーラーを実行し、バックアップしたアプリデータを保持します。ポータブル版は旧アプリを終了し、新しい ZIP を別の書き込み可能なフォルダーに展開します。起動前にバックアップした `data` 全体をその新しいフォルダーにコピーします。取り込んだ音声モデルを含めるため、会話の書き出しファイルだけでなく、データ全体を保持してください。新しい版でセーブ、設定、音声再生を確認するまで元のバックアップを残します。

元の Apache-2.0 `LICENSE` と `NOTICE` を保持しています。各構成要素の注意書きは配布物の `THIRD_PARTY_NOTICES.md` と音声環境のライセンスフォルダーにあります。Style-Bert-VITS2 のソースと AGPL ライセンスを音声環境に同梱します。キャラクター素材の権利は元の権利者に帰属し、ソースリポジトリには含めません。

## 0.2.0 の操作改善

短くクリックすると、独立した半透明のチャットウィンドウが開きます。長押しでは拡大やチャット表示が起きず、押している間のホイール操作でも拡大縮小しません。チャットは上部のタイトルバーで移動でき、縁・右下のハンドル・−/＋ボタンでサイズを変更できます。ミントはドラッグ、ホイール、−/＋ボタンで別々に移動・拡大縮小できます。下半身を画面の下端より下に置き、上半身だけ見せることもできます。見えている部分や上部の移動ハンドルをつかんで引き上げてください。完全に画面外へ消えないよう、操作できる領域を残します。更新では既存の設定・セーブ・読み込んだ音声モデルを維持します。
